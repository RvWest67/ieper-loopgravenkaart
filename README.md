# Loopgravenkaart Ieperboog 1914–1918

Interactieve WOI-kaart van de Ieperboog (Leaflet, Nederlandstalig, geschikt voor mobiel), gemaakt voor een weekend in Ieper (16–18 oktober 2026).

**Bekijk de kaart:** https://rvwest67.github.io/ieper-loopgravenkaart/

- `index.html` – de kaart (één bestand; frontlijnen, loopgraven en plekken zitten erin, achtergrondkaarten en WOI-luchtfoto's worden live geladen).
- `ww1-ieper.kml` – dezelfde 21 plekken, om te importeren in Google My Maps.

‘Mijn locatie’ vraagt locatietoegang in je browser.
